# Simulation Model

## 目的

この実装は、Goldberg多面体上でセルシミュレーションを行うための最小の基盤を作ることを目的にしています。

重要なのは、五角形セルを欠陥として捨てるのではなく、位相的に異なる特殊セルとしてモデルに残すことです。Goldberg多面体では五角形セルを完全には避けられないため、初期段階から通常セルと同じ配列に含めて扱います。

## セルモデル

各セルは `Cell` 型で表現します。

- `id: number`
  - セル ID
- `neighbors: number[]`
  - 隣接セルの ID 配列
- `neighborCount: number`
  - 近傍数。生成時に `neighbors.length` を保存したもの
- `isPentagon: boolean`
  - 五角形セルかどうか
- `state: number`
  - 現在ステップの状態値
- `nextState: number`
  - 次ステップの状態値

この設計により、五角形セルだけを描画で色分けしたり、後で更新ルールを分けたりできます。変更時の作業上の不変条件は `AGENTS.md` にまとめています。

## メッシュの前提

現在の生成器は `frequency` 可変の Goldberg多面体メッシュを使います。

- 総セル数は `10 * frequency^2 + 2`
- 五角形セルは 12
- 五角形セルはすべて 5 近傍
- それ以外のセルは 6 近傍

ここでは icosahedron を細分化した三角形メッシュから dual を構成し、dual 側の各頂点周りを 1 セルとして扱っています。現在のブラウザ表示は `frequency=10` ですが、生成器は `createGoldbergMesh(frequency)` により可変です。

## 五角形セルを除外しない理由

五角形セルを除外すると、球面上のトポロジーと近傍構造が壊れます。この実装では以下を優先します。

- 球面メッシュとして自然な隣接関係を保つ
- 五角形セルも通常更新ループに含める
- ただし `isPentagon` と `neighborCount === 5` で後から特別扱いできるようにする

つまり、五角形セルは「欠損」ではなく「5 近傍の特殊セル」です。

## 固定環境と可変状態

現在の惑星モデルでは、セルは大きく 2 種類の情報を持ちます。

- 固定または変わりにくい環境
  - `terrainKind`: `water` または `land`
  - `baseFertility`: 初期地形としての肥沃度
  - `geology`: 地質由来の育ちやすさ
- 時間変化する状態
  - `moisture`
  - `vegetation`
  - `fertility`

`water` セルは固定地形として扱い、植生更新の対象にはしません。

### `water` 固定セルの現在の配置ルール

初期環境の `water` セルは、完全なランダム配置ではなく、球面上の 2 つの基準方向から決めています。

- `waterPoleA = (0.65, 0.22, 0.72)`
- `waterPoleB = (-0.58, -0.31, 0.75)`

各セル中心の正規化ベクトルとこの 2 つの基準方向との内積を比べ、より大きい方を `waterScore` として使います。現在は `waterScore > 0.84` を満たすセルを `water` とし、それ以外を `land` としています。

この配置ルールにより、`water` は球面上にいくつかのまとまりを持って現れます。局所的な湿潤域を最初から作るため、植生の成長が全面一様になりにくく、`水場の近くで草が育ちやすい` というルールの見え方を作りやすくしています。

## 更新ルール

更新ルールは平均化モデルではなく、局所環境ルールです。

`land` セルの植生は、少なくとも次の要素で増減します。

- 隣接 `water` セルの多さ
- 周囲セルの植生量
- そのセル自身の `fertility`
- そのセル自身の `geology`
- 水も植生も乏しい場合の減衰

つまり、`水場の近くでは草が生えやすい` を直接ルールとして表現しています。

現在の `vegetation` 成長は、`moisture` が多いほど単調に有利になる形ではありません。`idealMoistureForGrowth` を頂点とする山型の適性帯を持ち、乾きすぎても湿りすぎても `moisture` 起因の成長は弱まります。さらに `fertility` はこの最適帯を少し乾燥側へずらし、`fertility` と `geology` は、少し湿り気があるだけでも独立に成長を後押しする通路を持っています。これにより、同じ程度に湿っていても、肥沃で地質条件のよいセルの方が先に立ち上がりやすくなります。

さらに `fertility` 自体もゆっくり変化します。植生が続くと少し回復し、乾いた裸地が続くと少し失われ、過湿や `water` 近傍が強すぎる状態では少し流され、最終的には `baseFertility` へ弱く戻るようにしています。これにより、地形の初期個性を残しつつ、セルオートマトン由来の履歴が土壌側にも少し蓄積します。

### なぜこの形にするか

平均化のみで更新すると、時間とともに全体が均質化しやすくなります。一方、このモデルでは固定の水場とセル固有の資源・地質があるため、草地は局所的に残りやすく、乾燥帯は草が広がりにくい構造を維持できます。

## テストで保証していること

- `frequency=2` で 42 セル、`frequency=3` で 92 セルになる
- 五角形セルが 12 個である
- 五角形セルの `neighborCount` がすべて 5
- 非五角形セルの `neighborCount` がすべて 6
- 隣接関係が双方向である
- 水場と土地の両方が生成される
- 水場近傍の土地セルが植生成長しやすい
- `nextVegetation` が各ステップで `vegetation` と `state` に反映される
