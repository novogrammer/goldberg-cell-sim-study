# Simulation Model

## 目的

この実装は、Goldberg多面体上でセルシミュレーションを行うための最小の基盤を作ることを目的にしています。

重要なのは、五角形セルを欠陥として捨てるのではなく、位相的に異なる特殊セルとしてモデルに残すことです。Goldberg多面体では五角形セルを完全には避けられないため、初期段階から通常セルと同じ配列に含めて扱います。

## セルモデル

各セルは `Cell` 型で表現します。

- `id: number`
  - セル ID
- `neighbors: number[]`
  - 隣接セルの ID 配列
- `neighborCount: number`
  - 近傍数。生成時に `neighbors.length` を保存したもの
- `isPentagon: boolean`
  - 五角形セルかどうか
- `state: number`
  - 現在ステップの状態値
- `nextState: number`
  - 次ステップの状態値

この設計により、五角形セルだけを描画で色分けしたり、後で更新ルールを分けたりできます。変更時の作業上の不変条件は `AGENTS.md` にまとめています。

## メッシュの前提

初期実装は固定の `frequency=2` の Goldberg多面体メッシュを使います。

- 総セル数は 42
- 五角形セルは 12
- 五角形セルはすべて 5 近傍
- それ以外のセルは 6 近傍

ここでは icosahedron を細分化した三角形メッシュから dual を構成し、dual 側の各頂点周りを 1 セルとして扱っています。

## 五角形セルを除外しない理由

五角形セルを除外すると、球面上のトポロジーと近傍構造が壊れます。この実装では以下を優先します。

- 球面メッシュとして自然な隣接関係を保つ
- 五角形セルも通常更新ループに含める
- ただし `isPentagon` と `neighborCount === 5` で後から特別扱いできるようにする

つまり、五角形セルは「欠損」ではなく「5 近傍の特殊セル」です。

## 更新ルール

更新ルールは近傍合計ではなく近傍平均を使います。

各セル `cell` に対して:

```text
neighborAverage = sum(neighbor.state) / cell.neighborCount
```

この平均値を `updateCell(cell, neighborAverage, context)` に渡して次状態を計算します。

### なぜ平均を使うか

近傍合計をそのまま使うと、5 近傍の五角形セルと 6 近傍のセルで入力スケールが変わります。平均を使えば、近傍数が異なっても比較可能な値で更新できます。

このため、五角形セルを除外せずに同じルール系へ載せやすくなります。

## 現在のルールの性質

現行実装では全セルが同じ更新関数を使います。

- `neighborAverage` が高いと活性化方向へ寄る
- 低いと減衰方向へ寄る
- 自身の状態と近傍平均を `coupling` で混ぜる

将来はここで `cell.isPentagon` を見て、五角形セルだけ別ルールへ分岐できます。

## テストで保証していること

- Goldberg多面体メッシュが 42 セルである
- 五角形セルが 12 個である
- 五角形セルの `neighborCount` がすべて 5
- 非五角形セルの `neighborCount` がすべて 6
- 隣接関係が双方向である
- 更新が近傍平均ベースで行われる
- `nextState` が各ステップで `state` に反映される
